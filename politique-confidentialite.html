2. Recherche par ville ou code postal

Lorsque vous saisissez une ville ou un code postal, le site utilise cette information pour construire une recherche vers Google Maps.

Selon le fonctionnement actuel du site, cette saisie est traitée dans votre navigateur et n'est pas enregistrée dans une base de données propre à Pharmacie de Garde Proche.

Lorsque vous ouvrez Google Maps, ce service applique sa propre politique de confidentialité.

3. Géolocalisation facultative

Le bouton « Autour de moi » peut demander l'autorisation d'accéder à votre position géographique.

Cette autorisation est facultative. Si vous l'accordez, votre position est utilisée pour lancer une recherche de pharmacies à proximité via un service cartographique externe.

Selon le fonctionnement actuel du site, Pharmacie de Garde Proche ne conserve pas votre position dans une base de données propre au site.

Vous pouvez retirer l'autorisation de géolocalisation dans les paramètres de votre navigateur ou de votre appareil.
